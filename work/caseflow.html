CaseFlow

Investigation cases routed fairly — under measurable load.

Events become assigned work through queues and rules, with SLA visibility and a live Throughput Console.

  • Custom Business Management Systems

Built on a pattern from my role as Software Engineer (Backend) at Data Gear (Fintech · Anti-money laundering). Rebuilt from scratch as a public demo — no employer code or data.

Open live demo ↗See the architecture

Problem

Ops teams drown when cases pile up without fair assignment, clear routing, or visibility into queue depth and SLA risk.

Solution

A multi-tenant case engine that ingests events, evaluates routing rules, assigns agents round-robin with skill tags, tracks SLAs, and audits every transition — demoable via load simulation.

Architecture — how a request flows

  1. edgePOST /api/eventsREST + JWT ingest
  2. queuecaseflow.ingestRabbitMQ queue
  3. logicRouting rulespriority + skill match
  4. queuecaseflow.assignRabbitMQ queue
  5. logicRound-robinfair agent selection
  6. storePostgreSQLcases + audit trail
