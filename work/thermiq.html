Thermiq HVAC Services

A service-business site that books real visits, not just enquiries.

Homeowners see prices, size their AC and book a slot in one visit — the site enforces crew capacity and opening rules.

  • Engineering & MEP Websites
  • Service-Based Business Websites

Fictional client — the company, people, projects and reviews are invented for this demo. The code, forms and business rules are real.

Open live demo ↗How it’s built

Problem

Small service companies lose jobs between the website and the phone: no prices, no availability, and booking requests that arrive for Fridays or for slots that are already full.

Solution

A conversion-focused Spring Boot site with live slot availability, a booking engine on Spring Data JPA that applies horizon, closed-day, lead-time and capacity rules in Cairo time, server-priced maintenance plans and an AC sizing calculator.

How a page request is handled

  1. edgeBrowserBootstrap 5, sticky mobile CTAs
  2. logicSpring MVCcontrollers + Bean Validation
  3. logicBookingServicepolicy + capacity rules
  4. storeSpring Data JPAbookings in H2
  5. edgeThymeleaflayout + shared fragments

edgelogicstore

Highlights

  • Booking rules: past dates, 30-day horizon, closed days, 2-hour lead time, crews per slot
  • Rule violations come back as field errors on the form, not error pages
  • Six-day availability grid from one grouped count query; next free slot on the home page
  • AC sizing calculator and per-unit plan pricing with a yearly discount
  • Mobile sticky Call / WhatsApp / Book bar

Tech

  • Java 21 / Spring Boot
  • Spring MVC
  • Thymeleaf layouts
  • Bootstrap 5
  • Bean Validation
  • Spring Data JPA
  • H2 → PostgreSQL-ready
